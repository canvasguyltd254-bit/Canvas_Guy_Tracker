Developer contract

Release A · visibility

  • Enrich enquiry reads from web_form_submissions.
  • One dataset powers desktop and mobile.
  • Website, source, brand, consent and attribution are read-only.
  • Consent time is labelled “Recorded at”.

Release B · contact SLA

  • Use an atomic mark_enquiry_contacted function.
  • Store first contact time, user, method and note.
  • One business hour, 08:00–18:00 Mon–Sat, Nairobi time.
  • Automatic acknowledgements never stop the clock.

Release C · customer match

  • Reuse the existing exact phone/email match result.
  • Resolve ambiguous matches with one database function.
  • Record linked/kept-as-prospect, resolver and timestamp.
  • Never update enquiry and submission separately.

Release D · alerts

  • Email only in the first release.
  • Never roll back a saved enquiry because an alert failed.
  • Track queued, sent, failed and provider message ID.
  • Daily digest reconciles missed alerts.
